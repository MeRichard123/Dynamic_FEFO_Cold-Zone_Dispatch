# Phase 1 dataset

4,000 simulated warehouse-dispatch examples: 3,192 train, 380 validation,
and 428 test. Choose CSV or JSONL; they contain the same examples.

- JSONL: use `messages` for training (system, user input, assistant target).
- CSV: use `system`, `input`, and `output`. The output is a JSON dispatch plan.
- `metadata` / `metadata_json`: provenance and replay information for audit.
  These contain solver controls and should not be appended to model inputs.

Each line in JSONL, or row in CSV, is one example. Splits keep all variants of
a source workload together. `manifest.json` records counts and file checksums.

Labels are generated by a literature-conditioned simulation. There are 2,000
controls, 1,500 procedural-fault examples, and 500 replays of one saved Ollama
scenario. These are not 4,000 independent LLM generations or field observations.

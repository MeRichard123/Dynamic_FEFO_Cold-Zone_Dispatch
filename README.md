# Phase 1 warehouse-dispatch dataset

The final dataset is in **[dataset/](dataset/README.md)**.

| Split | Examples | CSV | JSONL |
| --- | ---: | --- | --- |
| Train | 3,192 | [train.csv](dataset/train.csv) | [train.jsonl](dataset/train.jsonl) |
| Validation | 380 | [validation.csv](dataset/validation.csv) | [validation.jsonl](dataset/validation.jsonl) |
| Test | 428 | [test.csv](dataset/test.csv) | [test.jsonl](dataset/test.jsonl) |

There are 4,000 unique examples, available in either format. Each JSONL line or
CSV row is one example. Use `messages` in JSONL, or `system`, `input`, `output`
in CSV, for training. Audit metadata contains solver controls and replay data;
it is not an additional model input.

The dataset's manifest records counts and checksums. Labels are generated by a
literature-conditioned simulation: 2,000 controls, 1,500 procedural-fault cases,
and 500 replays of one saved Ollama scenario. They are not field observations
or 4,000 independent model generations.

Generated run folders, individual solution files, checkpoints, logs, old pilot
exports and caches have been removed. The final dataset is verified and kept.
Batch-resume checkpoints are no longer retained. Source code, tests, original
downloads and the small reusable template/scenario inputs remain available.

## Optional regeneration

The preserved template and recorded scenario can generate a new run:

```bash
.env/bin/python -m warehouse_sim.stage1 batch-build \
  --dataset 'Order Picking Dataset from a Warehouse of a Footwear Manufacturing Company.zip' \
  --template examples/paper-template.json \
  --scenario data/generated-42.json \
  --grid data/grid-2023-01-05.json \
  --variant-suite standard --cases 1000 --resume \
  --output runs/phase1-regenerated
```

[Parameter sources and assumptions](docs/paper-parameters.md) describe the model.
[Implementation guide](docs/implementation-guide.md) preserves the earlier
workflow documentation; its historical run-output paths were cleaned up.
Stage 2 visual spoilage and VLA work is outside this dataset.
